# 🚀 SpotConnect Engine

**SpotConnect Engine** es el motor conversacional y de mensajería masiva diseñado para la gestión en tiempo real de eventos, congresos y recintos de gran escala.

## 🛠️ Tech Stack

* **Language:** Python 3.10+
* **Framework:** FastAPI
* **Server:** Uvicorn
* **API:** WhatsApp Business API (Meta)
